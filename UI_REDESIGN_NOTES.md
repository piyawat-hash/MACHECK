# MACHECK — Responsive UI Notes

## Desktop

- Teacher Command Center uses a left vertical purple sidebar.
- MACHECK logo sits on a white brand card for contrast.
- A sticky top bar displays the current section, teacher profile and sign-out.
- Main content area is wide and dashboard-oriented.

## Mobile

- Student Fast-Pass uses a single-column mobile layout with a purple hero header.
- The approved purple MACHECK logo is shown on a white plate for legibility against the purple header.
- Student ID card, personal QR, today's check-in status and QR scanner remain in the mobile flow.
- Bottom navigation uses safe-area padding for modern phones.
- Teacher mobile view keeps the command-center functions and moves its navigation to a bottom bar.

## Brand assets

- `public/logo.png`: approved purple MACHECK logo.
- `public/crest.png`: Yothin Nukul School crest.
- `public/icon-192.png`, `public/icon-512.png`: PWA icons generated from the approved logo on a light background for adequate contrast.
