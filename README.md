# MACHECK

MACHECK is a school attendance and student-work tracking pilot for Yothin Nukul School.

- Live GitHub Pages site: https://piyawat-hash.github.io/MACHECK/
- Source: https://github.com/piyawat-hash/MACHECK
- Backend: Firebase Authentication, Cloud Firestore and Cloud Functions.
- Current release target: single-school supervised pilot.

See [README_TH.md](README_TH.md) for Thai setup, migration, deployment and pilot-safety instructions. The Director Overview is for school administrator accounts. The release must pass Firebase Rules/Emulator and supervised pilot checks before real student data is used.
